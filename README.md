# Open-Claw-Basic

An AI-powered agent that controls your machine through natural language commands. Built with Node.js, Express, and OpenRouter AI.

## What it does
Send a plain English message and the agent will execute the appropriate shell command on your machine.

## Examples:
- "Create a file named testing.txt"
- "Make a folder called projects"
- "Build me a todo app"

## Tech Stack
- Node.js + Express (REST API)
- OpenRouter AI (stepfun/step-3.5-flash model)
- OpenAI SDK


## Project Structure

open-claw/
├── index.js        # Express server
├── agent1.1.js     # AI agent logic
└── todo-app/       # Sample app generated by the agent
